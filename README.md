# 몽글 Pop Pop!

거품으로 적을 가두고 터뜨려 말랑한 젤리를 모으는 한 화면 플랫폼 게임이에요.
설치 없이 브라우저에서 바로 실행돼요.

## 버전

| 버전 | 폴더 | 내용 |
|---|---|---|
| **ver 1** | [`v1/`](v1/) | 기본 게임. 맵 6개 무한 반복, 1인/2인 협동, TOP 10 랭킹 |
| **ver 2** | [`v2/`](v2/) | 영단어 퀴즈. 물음표 몬스터를 터뜨리면 초등 필수 영단어 4지선다 문제 |

GitHub Pages 주소의 첫 화면(`index.html`)에서 버전을 골라 플레이해요.

## 폴더 구조
```
index.html          버전 선택 화면
v1/index.html       ver 1 게임 (파일 하나로 동작)
v2/index.html       ver 2 영단어 퀴즈 게임
apps-script/Code.gs 구글 시트 랭킹 서버 코드
```

## 조작 (ver 1)
| | 이동 | 점프 | 거품 |
|---|---|---|---|
| 1인 | ← → | Z / Space | X |
| 2인 · 몽이 (1P) | A D | W | F |
| 2인 · 글이 (2P) | ← → | ↑ | L |

시작 Enter · 일시정지 P 또는 Esc · 폰에서는 화면 아래 터치 버튼

## 규칙 (ver 1)
- 거품으로 적을 가두고 몸으로 부딪쳐 터뜨리면 적이 젤리로 바뀌어요.
- 붙어 있는 거품은 함께 터지는 **연쇄**가 일어나요. 연쇄 순서에 따라 초록 → 파랑 → 보라 → 분홍 → 금빛 → 무지개 젤리가 나와요.
- 맵 6개를 끝없이 반복하고, 한 바퀴마다 적이 빨라져요.
- 35초가 지나면 HURRY UP!, 45초가 지나면 유령이 쫓아와요.

## 영단어 퀴즈 (ver 2)
- 라운드마다 금색 **물음표 몬스터**가 1마리(적이 7마리 이상인 맵은 2마리) 나와요.
- 물음표 몬스터를 터뜨리면 게임이 멈추고 4지선다 문제가 나와요. 숫자 키 1~4나 터치로 답해요.
  - 뜻(그림) → 영어 고르기, 영어 → 뜻 고르기가 섞여 나와요. 🔊 버튼으로 발음을 들을 수 있어요.
- 맞히면 보너스 3,000점과 무지개 젤리, 틀리면 감점 없이 정답을 알려 줘요.
- 게임오버 화면과 설명 → **단어** 탭에서 이번 판 정답 수와 틀린 단어를 다시 볼 수 있어요.
- 단어는 `v2/index.html`의 `WORDS` 목록에 `['영어', '뜻', '그림', '분류']` 형태로 있어요. 줄을 추가하거나 지워서 바꿀 수 있어요.

## 랭킹 (구글 시트)
TOP 10 기록은 구글 시트에 저장돼요. 시트 탭 이름이 게임 버전(`v1`, `v2`)이에요.
랭킹 주소가 설정되지 않았거나 연결이 안 되면, 기록은 그 기기의 브라우저에만 저장돼요.

### 처음 설정하는 방법
1. 구글 시트를 새로 만들어요. (이름 예: `몽글 Pop Pop! 랭킹`)
2. 메뉴 **확장 프로그램 → Apps Script**를 열어요.
3. 원래 있던 코드를 모두 지우고 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 붙여 넣은 뒤 저장해요.
4. **배포 → 새 배포** → 유형 선택(톱니바퀴)에서 **웹 앱**을 골라요.
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르고 권한을 승인해요. "확인되지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 눌러요.
6. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 `v1/index.html`의 `RANKING_URL`에 넣어요.

### 관리
- 장난 기록은 시트에서 그 행을 지우면 순위표에서도 사라져요.
- 저장 주소는 공개돼 있어서 누구나 점수를 보낼 수 있어요. 학급용으로 쓰기에는 시트에서 정리하는 정도로 충분해요.
