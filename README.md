# 몽글 Pop Pop! (ver 1.0)

거품으로 적을 가두고 터뜨려 말랑한 젤리를 모으는 한 화면 플랫폼 게임이에요.
설치 없이 브라우저에서 바로 실행되는 HTML 파일 하나로 되어 있어요.

## 플레이
- `index.html`을 브라우저로 열거나, GitHub Pages 주소로 접속하세요.
- PC 키보드와 모바일 터치를 지원해요.
- 1인 플레이 또는 한 키보드로 하는 2인 협동을 고를 수 있어요.

## 조작
| | 이동 | 점프 | 거품 |
|---|---|---|---|
| 1인 | ← → | Z / Space | X |
| 2인 · 몽이 (1P) | A D | W | F |
| 2인 · 글이 (2P) | ← → | ↑ | L |

시작 Enter · 일시정지 P 또는 Esc

## 규칙
- 거품으로 적을 가두고 몸으로 부딪쳐 터뜨리면 적이 젤리로 바뀌어요.
- 붙어 있는 거품은 함께 터지는 **연쇄**가 일어나요. 연쇄 순서에 따라 초록 → 파랑 → 보라 → 분홍 → 금빛 → 무지개 젤리가 나와요.
- 맵 6개를 끝없이 반복하고, 한 바퀴마다 적이 빨라져요.
- 35초가 지나면 HURRY UP!, 45초가 지나면 유령이 쫓아와요.
